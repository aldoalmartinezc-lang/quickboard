# QuickBoard Glossary

## Board
Contenedor principal que agrupa listas y cards relacionadas dentro de un mismo flujo de trabajo.

## List
Columna o estado dentro de un board, por ejemplo Todo, Doing o Done. Una lista contiene cards ordenadas.

## Card
Unidad de trabajo individual con título, descripción, estado y posición dentro de una lista.

## Tag
Etiqueta de texto libre asociada a una card para clasificar, filtrar o agrupar trabajo.
